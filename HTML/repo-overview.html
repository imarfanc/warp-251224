Personal macOS developer toolkit & configuration repository

This is a personal toolbox repository for macOS development workflows. It contains two local web applications (a process launcher and a Markdown browser), Keyboard Maestro automation macros, AI coding-tool configurations, and assorted data/scripts. It is not a library or framework — it is a working environment.

Core Applications

1. just-runner Node.jsExpressWebSocket

A multi-process launcher panel for web-app just recipes.

  • Start with: just just-runner (installs deps then runs node server.js)
  • Serves a local web UI from APPS/just-runner/public/
  • Cards defined in card-groups.json and local-cards.json
  • Front-end logic lives in panels.js

2. markdown-browser DenoTypeScriptWeb Components

A local Markdown file browser and renderer with rich navigation features.

  • Backend: Deno HTTP server at localhost:8000 (main.ts)
  • Start with: deno task start (bundles front-end TS, then serves)
  • Front-end: vanilla TypeScript with custom Web Components (no framework)
  • Features: file-tree sidebar, Prism.js syntax highlighting, code-copy buttons, H2-jump FAB, settings persistence
  • Reads .root-config.json to know which directories to serve
  • Uses Iconify for icons, unified/remark for Markdown processing
